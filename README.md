Enterprise Procurement System
A comprehensive procurement management platform designed to streamline corporate purchasing. Built with Java, Spring Boot, and Spring Data JPA to serve a React frontend, this RESTful API handles the complete order lifecycle from request generation to supplier fulfillment.

Key Features:

*Role-Based Authentication: Secure JWT-based access control for Admins, Users, and Suppliers.

*Automated Order Routing: Dynamic category-based mapping to auto-assign procurement requests to appropriate suppliers.

*Secure Payments: MPIN and QR-code verification flows for secure supplier transactions.

*Real-Time Notifications: Asynchronous SMTP email alerts for order approvals, status updates, and dispatch routing.

*Supplier Management: Track outstanding balances, fulfillment metrics, and user feedback ratings.
